Часть I

Теория за пять минут

01

Как устроен RAG

Без этого раздела можно жить, но с ним вы будете понимать, что именно настраиваете — и почему система иногда отвечает невпопад.

Большая языковая модель (LLM) — это эрудит с замороженной памятью. Она прочитала пол-интернета, но ни разу не видела ваш СП в последней редакции и вашу исполнительную документацию. Хуже того: не зная ответа, она уверенно его выдумает. Это называется галлюцинацией.

RAG меняет правила игры. Перед ответом система идёт в вашу библиотеку, находит релевантные фрагменты и кладёт их модели на стол со словами: «отвечай по этому». Модель перестаёт сочинять — она пересказывает найденное.

Обратите внимание на стрелку из «Векторного индекса» в «Поиск»: вопрос и документы живут в одном «смысле-пространстве», поэтому система находит ответ даже тогда, когда слова в вопросе и в документе не совпадают.

02

Эмбеддинги: как машина понимает смысл

Ключевая идея всего RAG — текст можно превратить в координаты.

Каждый фрагмент текста специальная модель (embedding-модель) превращает в набор чисел — точку в многомерном пространстве. Тексты со схожим смыслом оказываются рядом, с разным — далеко.

Вопрос «какая толщина защитного слоя у колонн?» и пункт «…защитный слой бетона для колонн принимается не менее 20 мм» написаны разными словами, но на этой карте они соседи. Обычный поиск по ключевым словам такое совпадение пропустит — векторный найдёт.

Отсюда вывод
Качество поиска на 80% определяется embedding-моделью. Для русского технического языка берите модели с приставкой ru или мультиязычные — об этом в шаге 08.
03

Чанкинг: искусство нарезки

Документ нельзя скормить модели целиком — её контекстное окно ограничено. Поэтому текст нарезают на куски — чанки.

Тут прячется главный компромисс RAG:

НарезкаЧто происходитСимптом
Слишком мелко (~300 симв.)Цифра найдена, но заголовок раздела потерян«20 мм» без понимания, о чём речь
Слишком крупно (~4000 симв.)В куске пять разных тем сразуПоиск тянет мусор, модель путается
Оптимально (1000–2000)Один чанк = одна законченная мысльТочный ответ с полным контекстом

Эмпирическое правило для нормативки: граница чанка должна совпадать с границей смысла — пункт, подпункт, таблица. Именно поэтому «сырой» PDF лучше сначала перегнать в Markdown с сохранением заголовков.

04

Почему локально, а не в облаке

Три причины, по которым инженерный RAG не должен покидать периметр вашего ПК.

Конфиденциальность. Сметы, чертежи и исполнительная документация — коммерческая тайна. Локальная система физически не умеет отправлять данные наружу.

Автономность. На объекте часто нет стабильного интернета. Локальный RAG работает офлайн — хоть в бытовке, хоть в подвале.

Экономика. Разовая покупка железа против ежемесячных токенов. При регулярной работе с документацией локальная окупается за пару месяцев.

Теории достаточно

05

Ставим Ollama

Ollama — локальный рантайм для нейросетей. Думайте о нём как о Docker, но заточенном под LLM.

Windows

1

Скачиваем установщик

Заходим на ollama.com, жмём Download for Windows. Получаем OllamaSetup.exe.

2

Устанавливаем

Двойной клик → Install → Finish. В трее появится иконка ламы.

3

Проверяем

Win + R → cmd → Enter, затем команда ниже.

macOS / Linux

terminal
# установка одной строкой $ curl -fsSL https://ollama.com/install.sh | sh # Linux: включаем службу $ sudo systemctl enable ollama $ sudo systemctl start ollama # проверка $ ollama --version ollama version is 0.4.1
curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable ollama
sudo systemctl start ollama
ollama --version
Готово
ollama --version вернул номер версии — первый шаг пройден.
06

Грузим модель

Размер модели выбираем по объёму оперативки. Для русского технического языка оптимум — Qwen 2.5.

Подбор модели под ваше железо
terminal
# качаем модель (5–20 минут) $ ollama pull qwen2.5:14b # убеждаемся, что скачалась $ ollama list NAME SIZE MODIFIED qwen2.5:14b 9.0 GB Just now
ollama pull qwen2.5:14b
ollama list

Проверка: модель крутится на GPU или на CPU?

terminal — во время запроса
$ ollama ps NAME ID SIZE PROCESSOR qwen2.5:14b 8f2b41c9 9.2 GB 100% GPU ← отлично qwen2.5:14b 8f2b41c9 9.2 GB 45%/55% CPU/GPU ← памяти не хватает
ollama ps
Если видите большую долю CPU
Модель не влезла в видеопамять. Возьмите версию поменьше или закройте приложения, съедающие VRAM (браузер с кучей вкладок — главный враг).

Ставим интерфейс

09

Загружаем документацию

Создаём коллекцию знаний и скармливаем ей СП, ГОСТы и ТУ.

1

Создаём коллекцию

Левое меню → Documents → Create Collection → имя «СП и ГОСТы» → Create.

2

Кидаем файлы

Открываем коллекцию и перетаскиваем PDF прямо в окно браузера.

3

Ждём индексации

Статус каждого файла должен стать Indexed. PDF на 500 страниц — 5–15 минут.

Форматы
PDF, DOCX, TXT, Markdown — из коробки. PDF-скан сначала прогоните через OCR.
10

Проверяем в деле

Момент истины: отвечает система по документам или несёт отсебятину.

1

Подключаем коллекцию

В чате жмём скрепку → выбираем «СП и ГОСТы». Без этого RAG не работает.

2

Выбираем модель

Слева сверху — qwen2.5:14b или ваша.

СпрашиваемЖдёмТревога
«Минимальная толщина защитного слоя для колонн по СП 63.13330?»число + пунктразмытый ответ
«Отличия требований для агрессивных сред?»сравнение с разделамиобщие фразы
«Требования к космическим аппаратам?»«информация отсутствует»выдуманный ответ
Критерий успеха
Ответ ссылается на документ и пункт. На вопрос «вне базы» система честно говорит «не знаю».

14

FAQ

Ответы на вопросы, которые обычно прилетают в личку после публикации таких гайдов.

Потянет ли мой ПК без видеокарты? +
Да, но медленнее. На CPU модель 7b даёт примерно 5–15 токенов в секунду — для работы с документами терпимо. Видеокарта ускоряет в 5–10 раз, но не является обязательной.
Сколько ресурсов ест система в простое? +
Почти нисколько. Ollama автоматически выгружает модель из памяти через 5 минут бездействия (настраивается переменной OLLAMA_KEEP_ALIVE). Контейнер интерфейса в простое потребляет меньше 100 МБ ОЗУ.
Можно ли загрузить чертежи в DWG? +
Напрямую нет — текстовый RAG работает с текстом. Рабочий обходной путь: выгружать из CAD спецификации и ведомости в PDF/CSV и грузить их. Полноценный разбор графических форматов — отдельная большая тема.
Вышла новая редакция СП. Как обновить базу? +
Удаляете старый файл из коллекции, загружаете новый — индекс перестроится автоматически. Хорошая привычка: вести папку «Актуальные редакции» и обновлять коллекцию раз в квартал.
Как раздать систему коллегам по офисной сети? +
Поднять контейнер на адрес 0.0.0.0: docker run -d -p 0.0.0.0:3000:8080 ... — и коллеги заходят по вашему IP. Только помните: всё, что они загружают, попадает в общую базу. Для коммерчески чувствительных документов лучше держать систему персональной.
Модель отвечает медленно. Что делать? +
По порядку: проверить ollama ps (не уехала ли модель на CPU) → закрыть браузер и тяжёлые приложения → взять модель поменьше или квантование q4 → убедиться, что диск не забит под завязку.
15

Что дальше: лестница уровней

Базовый RAG — это уровень 1. Вот куда имеет смысл двигаться, когда система уже работает.

1

Базовый локальный RAG ✓ вы здесь

Поиск по вашим документам с ответами по источникам. Всё, что описано в этом руководстве.

2

Гибридный поиск (векторы + ключевые слова)

Точное нахождение шифров, марок и осей, с которыми чисто векторный поиск промахивается.

3

Реранкинг

Лёгкая модель-фильтр отсекает нерелевантные фрагменты до того, как они попадут в LLM. Галлюцинации падают кратно.

4

Граф знаний (GraphRAG)

Связи между пунктами, документами и сущностями. Система отвечает не «что написано», а «как это связано».

Кстати
Каждый уровень — это отдельный разбор. Когда выходит продолжение серии, оно публикуется в канале — чтобы не пропустить, подпишитесь ниже.

Глоссарий

Термины, которые встречаются в руководстве

LLM
Большая языковая модель. Обучена на огромном корпусе текстов, умеет продолжать текст. Не знает ваших файлов и выдумывает факты при нехватке данных.
RAG
Retrieval-Augmented Generation: перед ответом система находит в ваших документах релевантные фрагменты и модель опирается только на них.
Эмбеддинг
Числовое представление текста. Схожие по смыслу тексты получают близкие векторы — на этом работает семантический поиск.
Чанк
Фрагмент документа, который хранится и ищется отдельно. Размер нарезки напрямую влияет на качество ответов.
Топ-K
Количество наиболее релевантных фрагментов, которые передаются модели в контекст.
Галлюцинация
Правдоподобный, но неверный ответ: выдуманные пункты, цифры, ссылки.
Ollama
Локальный рантайм для запуска LLM: сам скачивает модели, управляет памятью, даёт простой API.
Docker / контейнер
Упаковка программы со всеми зависимостями; запускается одинаково на любой системе и не засоряет ОС.
OCR
Распознавание текста на изображениях. Нужно для PDF-сканов без текстового слоя.
VRAM
Память видеокарты. Именно в ней крутятся модели; при нехватке система сбрасывает веса в ОЗУ и теряет в скорости.
